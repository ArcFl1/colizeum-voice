# Голосовой чат Colizeum (Яркая, 40, г. Краснодар)

Страница для друзей из дома: открывается по ссылке-приглашению из голосовой
комнаты клуба (QuestHub → «Позвать друга из дома»). Без приглашения пишет
«Ссылка не работает» — так и должно быть.

Здесь только сама страница: ключей и данных клуба нет. Голос идёт через
облако LiveKit; адрес облака и пропуск приходят в ссылке после `#`.

Обновлять из папки QuestHub `deploy/voice-friends/web`.

`livekit-client.umd.js` — библиотека LiveKit (Apache License 2.0).
